Note that several of the libraries cited are forks of the originals, although they were slightly edited to better integrate within the pelicun\_2\_brightway2 workflow.

\- Python version : 3.11.4

\- pelicun version :  3.2b2

\- Brightway2 version : 2.4.3

\- pandas version : 2.0.0

\- numpy version : 1.25.2

\- Scipy version : 1.11.2
